# Диалоговая сцена

Версия 3.1.0. Требуется UniCanvas 2.5.0. Новое: таблица стартовых реплик (RollTable UUID) в настройках сцены; пресеты торговца, кузнеца и заказчика; сохранение собственных пресетов; Actor UUID у персонажей; выдача группе страницы квеста Simple Quest по UUID через ответ игрока. Сущности индексируются страницами Foundry, ссылка копируется кнопкой UUID в редакторе.

Независимый модуль кинематографичных диалогов для Foundry VTT 13–14.

- Отдельный список персонажей: имя, роль, портрет и цвет оформления
- Несколько независимых сцен с собственными фонами и графами реплик
- Визуальный редактор нодов на базе UniCanvas
- Ветвящиеся ответы без встроенной системы проверок
- Условия ответов на основе решений, принятых в предыдущих сценах
- Последствия выбора: переменные истории и изменение отношения персонажей
- Открытие городских точек и улик «Чертогов разума» прямо из ответа
- Точная привязка открытия к городу, экрану и доске даже при повторяющихся ID
- Стилизованная обратная связь об изменении отношений и новых зацепках
- Состояние кампании с безопасным сбросом для нового прохождения
- Подтверждение игровых последствий активным мастером без ложных клиентских срабатываний
- Идемпотентные сетевые выборы и отдельный повтор временно неудавшихся интеграций
- Внутренний голос, история разговора, чат и лист персонажа
- Редактор мастера и открытие сцены сразу у всех игроков
- Глобальные персонажи, доступные во всех сценах
- Готовый русский пример из двух сцен
- Интеграция с точками интереса City Viewer
- Отмена и повтор до 50 действий (`Ctrl+Z` / `Ctrl+Shift+Z`)
- Безопасный экспорт и импорт проекта в JSON
- Предзагрузка фонов и портретов ближайших реплик без визуальных скачков
- Очередь автосохранения без гонок и аварийное сохранение при закрытии редактора
- Защищённая синхронизация показа через авторитетное состояние мира
- Локализованные системные имена новых сцен, персонажей и реплик
- Совместимая с Foundry 14 группа кнопок в левой панели Scene Controls

После активации используйте кнопку **Диалог**. Кнопка с карандашом открывает редактор мастера.

## API

`game.modules.get("dialogue-stage").api` предоставляет методы `open`, `close`,
`openEditor`, `show`, `hide`, `getProject`, `getStoryState`, `setVariable`,
`changeRelationship`, `resetStoryState`, `applyChoice`, `exportProject` и
`importProject`.
После регистрации API вызывается хук `dialogueStage.apiReady`.
`show` и `hide` возвращают `Promise<boolean>` и отклоняют вызов не-мастера
значением `false`.
`applyChoice(sceneId, nodeId, choiceId, options)` принимает необязательные
`options.userId` и `options.requestId`; стабильный `requestId` делает повторный
сетевой вызов идемпотентным.

После применения ответа вызывается `dialogueStage.choiceApplied`. Изменение
состояния через API вызывает `dialogueStage.storyStateChanged`, а сброс —
`dialogueStage.storyReset`.
