# Mind Palace

Версия **2.8.0**, требуется **UniCanvas 2.6.0**. Редактор: светлая и тёмная темы, поиск (Ctrl+K), сохранение (Ctrl+S) и статус автосохранения. Новые карточки — в меню «Добавить», дедукции, UUID и экспорт — в «···».

Независимая интерактивная доска расследования для Foundry VTT 13–14.

- Карточки людей, документов, улик, заметок и свободного текста
- Связи между карточками и персональное расположение для каждого пользователя
- Совместные дедукции: игроки соединяют видимые улики, а совпавшая схема
  раскрывает вывод и при необходимости открывает скрытую карточку
- У одной дедукции может быть до 20 последствий: открытие карточек и точек
  City Viewer, установка или прибавление переменной Dialogue Stage, запуск
  конкретного дела Chronicle и текст для игроков
- Мастер настраивает цели через списки сущностей, видит состояние доставки и
  безопасно повторяет только незавершённые последствия
- Прогресс нерешённых правил показывается без названий, описаний и состава
  решения; мастер может раскрыть или сбросить правило вручную
- Личные заметки игроков, которые сохраняются только в их клиентских настройках
- Отмена и повтор до 50 действий (`Ctrl+Z` / `Ctrl+Shift+Z`)
- Экспорт и проверяемый импорт проекта в JSON
- Сериализованное автосохранение без гонок и аварийный flush при закрытии
- Плавное перемещение: геометрия связей обновляется не чаще одного кадра
- Доступный интерфейс с клавиатурной навигацией и режимом reduced motion
- Совместимая с Foundry 14 группа кнопок в левой панели Scene Controls

## API

`game.modules.get("mind-palace").api` предоставляет методы `open`, `close`,
`openEditor`, `show`, `hide`, `getBoards`, `getDeductions`, `getConsequences`, `connectCards`,
`revealDeduction`, `resetDeduction`, `evaluateDeductions`, `exportProject` и
`importProject`, `retryConsequences`, а также `revealEvidence` (`revealNode` — совместимый псевдоним).
После регистрации API вызывается хук `mindPalace.apiReady`.
`show` и `hide` возвращают `Promise<boolean>` и отклоняют вызов не-мастера
значением `false`.

`getDeductions(boardId)` возвращает полные правила мастеру и безопасные
проекции прогресса игроку. `connectCards(boardId, from, to)` переключает общую
игровую связь; запрос игрока проверяется и сохраняется активным мастером.
Методы `revealDeduction`, `resetDeduction` и `evaluateDeductions` доступны
только мастеру.

`getConsequences(boardId, deductionId)` возвращает мастеру полные определения
и состояние доставки. Игрок получает только уже выполненные подписи и
текст для игроков — без внутренних ID города, экрана, точки, карточки
или переменной. `retryConsequences(boardId, deductionId, consequenceId?)`
доступен только мастеру, пропускает уже выполненные действия и возвращает
`{boardId, deductionId, delivered, failed, skipped, evidenceIds}`.

Контракт внешней доставки:

- City Viewer: `revealPoint(cityId, screenId, pointId, {source})`; перед вызовом
  Mind Palace проверяет ровно одну точную тройку ссылок. Старый demo-ID
  `north-workshops` разрешается в точную тройку один раз и сохраняется.
- Dialogue Stage: `setVariable(variableId, preparedValue)`. Для операции `add`
  абсолютное итоговое значение вычисляется через `getStoryState()` и
  сохраняется до внешнего вызова. Повтор после сбоя устанавливает то же значение
  и не применяет прибавление второй раз.
- Chronicle: `show(timelineId)` после проверки точного ID через `getProject()`.
  Готовое дело открывает хронологию `silver-burn-night`; после закрытия
  окна вывода игрок локально переходит к открытому делу.

Эти интеграции необязательны. Для них рекомендуются City Viewer 6.1.0+ и
Dialogue Stage 3.0.0+, Chronicle 1.0.0+; без активного модуля последствие
останется доступным для повтора, а остальные последствия той же дедукции
продолжат работу.

Успешные последствия имеют состояние `delivered` и больше не выполняются.
Ошибки сохраняются как `failed`; мастер может повторить их из редактора или API.
Незавершённые `pending`-действия безопасно возобновляет основной мастер после
перезапуска. Схема проекта — v4; новое продолжение автоматически добавляется
только узнаваемому встроенному делу `ashcroft-formula`, пользовательские доски
не получают примерные данные.

`revealEvidence(nodeId, {source, boardId?})` доступен только мастеру, требует
ровно одно совпадение ID среди досок, открывает скрытую карточку, сохраняет
проект и обновляет открытые viewer-экраны. Встроенный пример содержит
стабильную скрытую улику `silver-burn`; копии шаблона получают новые ID.

События интеграции: `mindPalace.playerLinksChanged`,
`mindPalace.deductionRevealed`, `mindPalace.deductionReset` и
`mindPalace.deductionOutcomes`. В событии
нераскрытого правила игроку не передаются его название, текст и условия.
Программное открытие карточки вызывает `mindPalace.evidenceRevealed` с полями
`boardId`, `node` и `source`.

На клиенте мастера каждая попытка вызывает
`mindPalace.consequenceDelivered` либо `mindPalace.consequenceFailed` с
`boardId`, `deductionId` и полной копией `consequence`; ошибка дополнительно
содержит безопасный код `reason`. Клиентский `mindPalace.deductionOutcomes`
получает только публичную проекцию дедукции.
