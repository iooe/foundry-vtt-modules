## Template images

`amberwind.webp` is a lossless WebP derivative of the user-supplied
`amberwind.png` project asset. The original PNG is retained outside the
runtime package as a recoverable development source.

The built-in templates include the following freely reusable images:

- **Fantasy cityscape with the Mauritshuis**, Bartholomeus Johannes van Hove — Public Domain Mark 1.0. Source: https://commons.wikimedia.org/wiki/File:Fancy_cityscape_with_the_Mauritshuis,_by_Bartholomeus_Johannes_van_Hove.jpg
- **Market Day in a Medieval Town**, Charles Hoguet — Public Domain Mark 1.0. Source: https://commons.wikimedia.org/wiki/File:Charles_Hoguet_-_Markttreiben_in_einer_mittelalterlichen_Stadt_(1862).jpg
- **Top-down RPG mockup scene**, drummyfish — CC0 1.0. Source: https://opengameart.org/content/top-down-rpg-mockup-scene
- **Interior of a Tavern**, Adriaen Brouwer — Public Domain Mark 1.0. Source: https://commons.wikimedia.org/wiki/File:Adriaen_Brouwer_-_Interior_of_a_Tavern.jpg
- **House Interior**, Théodore Jacques Ralli — Public Domain Mark 1.0. Source: https://commons.wikimedia.org/wiki/File:House_interior.jpg
- **The Interior of a Peasant’s Cottage**, Adriaen van Ostade — Public Domain Mark 1.0. Source: https://commons.wikimedia.org/wiki/File:The_Interior_of_a_Peasant%E2%80%99s_Cottage,_by_Adriaen_van_Ostade.jpg
